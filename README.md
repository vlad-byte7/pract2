# Визуализация зависимостей Maven — вариант 19

На первом этапе консольная программа читает CSV, проверяет настройки и
выводит их в формате `ключ = значение`. Нужен Python 3. Сборка и установка
сторонних библиотек не требуются.

## Запуск и тесты

В терминале VS Code из папки проекта:

```powershell
.\run.bat
.\run.bat .\config.csv
py -3 -m unittest discover -s tests -v
```

Если в системе используется команда `python`, тесты можно запустить через
`python -m unittest discover -s tests -v`.

## Настройки

Файл `config.csv` сохраняется в UTF-8, без заголовка. Каждая строка содержит
один параметр и его значение, разделённые запятой.

| Ключ | Пример | Назначение |
| --- | --- | --- |
| `package` | `org.apache.commons:commons-text:1.11.0` | Координаты Maven-пакета в формате `groupId:artifactId:version`. В тестовом режиме указывается одна буква от A до Z. |
| `repository` | `https://repo.maven.apache.org/maven2` | URL репозитория при `false`. Путь к существующему файлу при `true`. Относительный путь считается от папки с CSV. |
| `test_mode` | `false` | При `false` используется URL, при `true` — локальный файл. |

## Демонстрация обработки ошибок

Перед каждым запуском поменяйте одну строку в исходном `config.csv`:

| Строка | Сообщение |
| --- | --- |
| `package,commons-text` | `Ошибка: package: нужен формат groupId:artifactId:version` |
| `repository,maven2` | `Ошибка: repository: нужен корректный URL с http:// или https://` |
| `test_mode,yes` | `Ошибка: test_mode: допустимы только true и false` |

## Функции

- `main` обрабатывает аргументы запуска и выводит настройки или ошибку.
- `load_config` читает и проверяет конфигурацию.
- `read_settings` разбирает строки CSV и проверяет список ключей.
- `validate_settings` проверяет значения в соответствии с выбранным режимом.
- `validate_url` проверяет адрес Maven-репозитория.
